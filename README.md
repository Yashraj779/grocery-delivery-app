# Grocery Delivery Web App

A full-stack grocery delivery application built using React (Vite) and Node.js microservices architecture.

## Features
- Product browsing
- Cart management
- Order placement
- Delivery tracking
- Authentication (Login/Register)

## Tech Stack
- Frontend: React (Vite)
- Backend: Node.js, Express
- Database: MongoDB
- Architecture: Microservices

## Setup
1. Clone repo
2. Run `npm install`
3. Start backend services
4. Run frontend with `npm run dev`
